Our approach

We use occurrence time to position each earthquake horizontally and catalog depth to place it vertically. Magnitude sets circle size. Depth also changes circle color, so the data shapes the field as we explore it.

We fit the depth scale to the full time window and keep that scale while changing the magnitude filter. Negative catalog depths appear above the 0 km reference. Depth shading is illustrative, and point overlaps can hide events.

Our data comes from USGS M 2.5+ summary feeds. We request the latest snapshot when the page opens, when we change the time window, and when we select Refresh feed. Coverage varies by location, and USGS can revise these estimates.
